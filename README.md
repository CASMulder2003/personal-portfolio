# Christian Mulder · Personal portfolio

[Visit the portfolio](https://casmulder2003.github.io/personal-portfolio/)

Research, analysis and digital projects from my work in human geography and urban spatial science at Durham University and UCL.

The site includes twelve project cases and eight research notes. Each explains the question, contribution, methods and limits of the evidence. Source and data credits are provided within the relevant projects.

## Website

This is a static HTML, CSS and JavaScript site, published from the root of the `main` branch with GitHub Pages. Relative links support the repository URL.

The repository contains the public website and display assets. Original submissions, full source documents and private editorial notes are excluded. Font licences are included in `assets/fonts`.
